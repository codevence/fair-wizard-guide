Administration
**************

In Administration, we can manage users, roles, the audit log and login automations. The available options depend on our role. Authentication, appearance, translations, project options and integrations are described under Settings.

.. admonition:: With multiple workspaces

   Use the organization area for organization-wide administration. Workspace membership and local settings are managed for the selected workspace. Organization permissions can apply across workspaces, so review effective access when assigning roles.
