Users
*****

Open :guilabel:`Administration` → :guilabel:`Users` to find accounts, invite people and import users. Managing accounts requires **Manage Users**.
Search the list and open a user to review their profile, activation state and organization role.

With multiple workspaces, we need to add users to the workspaces they should use after creating their accounts. See :doc:`/administration/workspaces`.

Use :doc:`invite` for an individual invitation or :doc:`import` for a batch. See :doc:`/administration/roles` before assigning administrative permissions.
