Document Templates
******************

Users with the :ref:`Use Analytics<roles>` role permission can view analytics of document templates. We can create and edit views by selecting from many different fields and see how our document templates are doing. The view can be modified and saved to be reviewed later. The data can also be exported to a CSV file.

.. figure:: /_static/screenshots/5.0/guide/analytics-document-templates-list.png
    :figclass: guide-screenshot
    :alt: Analytics: Document Templates in FAIR Wizard 5.0
    :width: 800

    Analytics: Document Templates.

To configure the first view, open :guilabel:`View settings`, enter a name and choose the fields. Save the settings and use :guilabel:`Save changes` in the toolbar to keep the view.

To create another view while a saved view is selected, open the :guilabel:`View` menu and choose :guilabel:`Create new view`. We can return to saved views from the same menu.

.. figure:: /_static/screenshots/5.0/guide/analytics-document-templates-settings.png
    :figclass: guide-screenshot
    :alt: Analytics: Document Templates view settings in FAIR Wizard 5.0
    :width: 520

    Analytics: Document Templates view settings.

Various fields have filters that can be used to narrow down the data.

We can also resize all rows by clicking on the double arrow in the top left corner. If we want to change individual column widths or row heights, we can do it using drag-and-drop on the borders. We can choose how many rows are on the page by clicking on the :guilabel:`Items per page` dropdown menu.

.. NOTE::

    Click :guilabel:`Save changes` in the toolbar to keep changes to the view.


The data of a view can be exported to a CSV file by clicking on :guilabel:`Export CSV`.

Document template details
--------------------------

By clicking on the document template name, we can open that document template detail. The document template detail has three tabs:

- Readme
- Projects
- Documents

The :guilabel:`Readme` tab shows the README of the selected document template. The :guilabel:`Projects` tab shows all projects using the selected document template. The :guilabel:`Documents` tab shows all Documents that were generated using the selected document template, across all projects.

The document template details on the right side show additional document template metadata, such as ID, description, version, publisher, formats and knowledge models it can be used with.

Click :guilabel:`Go to document template` to open the template.
