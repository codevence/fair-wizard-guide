Knowledge Models
****************

Users with the :ref:`Use Analytics<roles>` role permission can view analytics of knowledge models. We can create and edit views by selecting from many different fields and see how our knowledge models are doing. The view can be modified and saved to be reviewed later. The data can also be exported to a CSV file.

.. figure:: /_static/screenshots/5.0/guide/analytics-knowledge-models-list.png
    :figclass: guide-screenshot
    :alt: Analytics: Knowledge Models in FAIR Wizard 5.0
    :width: 800

    Analytics: Knowledge Models.

To configure the first view, open :guilabel:`View settings`, enter a name and choose the fields. Save the settings and use :guilabel:`Save changes` in the toolbar to keep the view.

To create another view while a saved view is selected, open the :guilabel:`View` menu and choose :guilabel:`Create new view`. We can return to saved views from the same menu.

.. figure:: /_static/screenshots/5.0/guide/analytics-knowledge-models-settings.png
    :figclass: guide-screenshot
    :alt: Analytics: Knowledge Models view settings in FAIR Wizard 5.0
    :width: 520

    Analytics: Knowledge Models view settings.

Various fields have filters that can be used to narrow down the data.

We can also resize all rows by clicking on the double arrow in the top left corner. If we want to change individual column widths or row heights, we can do it using drag-and-drop on the borders. We can choose how many rows are on the page by clicking on the :guilabel:`Items per page` dropdown menu.

The data of a view can be exported to a CSV file by clicking on :guilabel:`Export CSV`.

.. NOTE::

    Click :guilabel:`Save changes` in the toolbar to keep changes to the view.


Knowledge model details
-----------------------

By clicking on the knowledge model ID or name, we can open that knowledge model detail. If we choose to click on a certain version of a knowledge model, that specific version detail will open. The knowledge model detail has four tabs:

- Readme
- Projects
- KM Editors
- Insights

The :guilabel:`Readme` tab shows the exact information that we can see in the knowledge model detail in FAIR Wizard. The :guilabel:`Projects` tab shows all projects that are using the selected knowledge model. The :guilabel:`KM editors` tab shows all knowledge model editors that are using the selected knowledge model. Both of these tabs also display numbers next to them, representing the number of created projects or knowledge model editors.

.. figure:: /_static/screenshots/5.0/guide/analytics-knowledge-models-detail.png
    :figclass: guide-screenshot
    :alt: Analytics: KM Editors using a Knowledge Model in FAIR Wizard 5.0
    :width: 800

    Analytics: KM Editors using a Knowledge Model.

The last tab, :guilabel:`Insights`, is the most complex. It shows us detailed information for each question and answer, such as the number of times a certain question was displayed to users and how these questions were answered. If we are viewing details of a value question, we can use search functionality to find the value we are interested in.

Furthermore, we can also open various questions to see insights into how the Researchers are answering them.

The knowledge model details on the right side show additional knowledge model metadata, such as ID, description, license and version.

Click :guilabel:`Go to knowledge model` to open the knowledge model.
