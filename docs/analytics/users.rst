Users
*****

Users with the :ref:`Use Analytics<roles>` role permission can view analytics of users. We can select from many different fields and see how our users are doing. The view can be modified and saved to be reviewed later. The data can also be exported to a CSV file.

.. figure:: /_static/screenshots/5.0/guide/analytics-users-list.png
    :figclass: guide-screenshot
    :alt: Analytics: Users in FAIR Wizard 5.0
    :width: 800

    Analytics: Users.

To configure the first view, open :guilabel:`View settings`, enter a name and choose the fields. Save the settings and use :guilabel:`Save changes` in the toolbar to keep the view.

To create another view while a saved view is selected, open the :guilabel:`View` menu and choose :guilabel:`Create new view`. We can return to saved views from the same menu.

.. figure:: /_static/screenshots/5.0/guide/analytics-users-settings.png
    :figclass: guide-screenshot
    :alt: Analytics: Users view settings in FAIR Wizard 5.0
    :width: 520

    Analytics: Users view settings.

Various fields have filters that can be used to narrow down the data.

Use the :guilabel:`User Groups` field filter to show users by group membership. Date fields such as :guilabel:`Created At` can be filtered by a date range.

We can resize all rows by clicking on the double arrow in the top left corner. If we want to change individual column widths or row heights, we can do it using drag-and-drop on the borders. We can choose how many rows are on the page by clicking on the :guilabel:`Items per page` dropdown menu.

The data of a view can be exported to a CSV file by clicking on :guilabel:`Export CSV`.

.. NOTE::

    Click :guilabel:`Save changes` in the toolbar to keep changes to the view.


User details
------------

By clicking on the first or last name of a user, we can open that user detail. The user detail has two tabs:

- Projects
- User Groups

The :guilabel:`Projects` and :guilabel:`User Groups` tabs show the number of respective items. In the :guilabel:`Projects` tab, we can see the list of projects this user is part of and their role in the project. In the :guilabel:`User Groups` tab, we can see the list of user groups where this user is a member or owner and the group visibility.

The user details on the right side show additional user metadata, such as role, email, or affiliation.

Click :guilabel:`Go to user` to open the user profile.
