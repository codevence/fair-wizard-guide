User Groups
***********

Users with the :ref:`Use Analytics<roles>` role permission can view analytics of user groups. We can create and edit views by selecting from many different fields and see how our user groups are doing. The view can be modified and saved to be reviewed later. The data can also be exported to a CSV file.

.. figure:: /_static/screenshots/5.0/guide/analytics-user-groups-list.png
    :figclass: guide-screenshot
    :alt: Analytics: User Groups in FAIR Wizard 5.0
    :width: 800

    Analytics: User Groups.

To configure the first view, open :guilabel:`View settings`, enter a name and choose the fields. Save the settings and use :guilabel:`Save changes` in the toolbar to keep the view.

To create another view while a saved view is selected, open the :guilabel:`View` menu and choose :guilabel:`Create new view`. We can return to saved views from the same menu.

.. figure:: /_static/screenshots/5.0/guide/analytics-user-groups-settings.png
    :figclass: guide-screenshot
    :alt: Analytics: User Groups view settings in FAIR Wizard 5.0
    :width: 520

    Analytics: User Groups view settings.

Various fields have filters that can be used to narrow down the data.

We can also resize all rows by clicking on the double arrow in the top left corner. If we want to change individual column widths or row heights, we can do it using drag-and-drop on the borders. We can choose how many rows are on the page by clicking on the :guilabel:`Items per page` dropdown menu.

The data of a view can be exported to a CSV file by clicking on :guilabel:`Export CSV`.

.. NOTE::

    Click :guilabel:`Save changes` in the toolbar to keep changes to the view.


User group details
------------------

By clicking on the user group name, we can open the user group details. The user group detail has two tabs:

- Members
- Projects

The :guilabel:`Members` and :guilabel:`Projects` tabs show the number of respective items. In the :guilabel:`Members` tab, we can see the members of the group and their role. In the :guilabel:`Projects` tab, we can see the projects that have the group assigned, as well as the role assigned to the user group.

.. figure:: /_static/screenshots/5.0/guide/analytics-user-groups-detail.png
    :figclass: guide-screenshot
    :alt: Analytics: User Group details in FAIR Wizard 5.0
    :width: 800

    Analytics: User Group details.

The user group details on the right side show user group metadata, such as the description or date created.

Click :guilabel:`Go to user group` to open the group.
