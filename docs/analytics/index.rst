Analytics
*********

Analytics reports on projects, knowledge models, document templates, users and user groups across the organization.
We can open Analytics from the main menu or workspace switcher, depending on the instance configuration. This requires the :guilabel:`Use Analytics` permission.

We can create and save views, choose columns and filters, open item details and export data.
Analytics shows data from the last successful synchronization. See :doc:`/settings/analytics` for synchronization settings.

.. admonition:: With multiple workspaces

   We can filter the results by workspace. The Use Analytics permission gives access to Analytics for the whole organization, including data from other workspaces.
