.. _project:

Project
*******

A project contains our answers to a questionnaire. It is based on a :ref:`knowledge model<knowledge-model>` and uses one or more :ref:`document templates<document-template>` to generate documents.

Projects are fully collaborative, so we can share them with other researchers and work together.


Questionnaire
=============

The questionnaire is part of the project where we fill in our answers. It is generated based on the selected knowledge model. It shows only the questions that are relevant based on our previous answers. Other features include FAIR metrics, comments, TODOs, or version history.


:ref:`Learn how to work with the questionnaire →<project-questionnaire>`

Documents
=========

Once we have enough answers to the questionnaire, we can generate a document using a document template. These documents are saved within the project. We can create documents with different templates and formats. We can also set up a default document template for the project and quickly see a preview of the document.


:ref:`Learn how to work with the documents →<project-documents>`
