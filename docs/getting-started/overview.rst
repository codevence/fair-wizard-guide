Overview
********

The main menu contains Projects, Knowledge Models, Document Templates, User Groups and administration. The available menu items depend on our permissions.
We can open :doc:`our account settings </account/index>` from the profile menu to change our profile, language, active sessions, API keys and connected AIs.

Workspace modes
===============

Professional uses a single workspace. Enterprise can also operate with a single workspace or use multiple workspaces.
In single-workspace mode, we can access the organization's projects and content directly, without a workspace switcher.

.. admonition:: With multiple workspaces

   We can use the workspace switcher to select a workspace or open the organization. Projects, members and local settings belong to the selected workspace. Organization administration and the shared library are accessed in the organization area.

Organization roles can grant access across workspaces, including to administrators and people with organization-wide project permissions. See :doc:`/administration/roles` when setting up access.

Analytics shows data for the whole organization. We can filter the results by workspace, but the Use Analytics permission gives access to the organization's Analytics data.

Dashboard
=========

The dashboard brings together the actions available to our account:

* Recent projects provide quick access to work we have opened recently.
* Create-project actions start a new project when the account and project settings permit it.
* Content actions provide shortcuts to create or import knowledge models and document templates.
* Update widgets show newer knowledge models or document templates from the connected Registry.
* The usage widget summarizes instance usage for accounts allowed to view it.
* Setup shortcuts can lead to appearance, Registry connection and OpenID configuration when further setup is needed.

The visible widgets depend on permissions, enabled features and the current setup. Dashboard announcements appear above them.
