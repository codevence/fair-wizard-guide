Get Help and Report an Issue
****************************

We can use :guilabel:`Report issue` to find the support contact configured for our instance.

Report a problem
================

#. Open the main navigation, then click our name or avatar at the bottom to open the profile menu.
#. Choose :guilabel:`Report issue`.
#. Follow the support-site link to report the problem there, or select the email address to open a message in our email application.
#. Complete and send the report through that site or email application. Click :guilabel:`OK` to close the contact dialog in FAIR Wizard.

The support site opens in a new tab. Its name and address can differ between instances. With multiple workspaces, the selected workspace can also have its own support contact.

What to include
===============

A useful report describes:

* What we were trying to do, and the steps that led to the problem.
* What we expected and what actually happened, including the displayed error message.
* The instance address and the affected project, knowledge model or document template, where relevant.
* When the problem occurred and whether we can reproduce it.
* The browser we are using and the FAIR Wizard version. We can find the FAIR Wizard version under :guilabel:`About` in the profile menu.

Add a screenshot when it helps explain the problem. Check the report and images for passwords, API keys or other information that should not be shared before sending them.

If we cannot sign in
====================

Contact the instance administrator using the support details provided by our organization. Describe which sign-in method we used and the error shown. An administrator can check the :doc:`authentication settings </settings/authentication/index>` and any :doc:`login automation </administration/automations>`.

For common problems with projects, templates and integrations, see :doc:`/reference/faq`. Administrators configure the contact links in :doc:`/settings/support`.
