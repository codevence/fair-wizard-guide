Profile
*******

In the profile menu, we can manage our profile, password, connected accounts, language, API keys and active sessions. We can also configure personal plugin and document-submission settings.

For support contact links, choose :guilabel:`Report issue` in the profile menu; see :doc:`/getting-started/support`.

We use the same account across FAIR Wizard. Our profile and personal plugin settings stay the same when switching workspaces.

Appearance and navigation
=========================

Choose :guilabel:`Appearance` in the profile menu to select :guilabel:`Light`, :guilabel:`Dark` or :guilabel:`System`. System follows the device's preferred appearance.

Open the command palette with :kbd:`Ctrl+K` (:kbd:`Cmd+K` on macOS) to search available pages and account actions. The results follow our permissions.
