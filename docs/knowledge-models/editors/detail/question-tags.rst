Question Tags
*************

If there are any :ref:`question tags<question-tag>` set up in the knowledge model, we can use the :guilabel:`Question Tags` tab to see the overview of which questions have these tags, and to assign the question tags to the questions.

We can click the checkbox in the table cell for a question tag and question to assign or remove the tag. We can also click on the question name to open the question editor and change the question details.
