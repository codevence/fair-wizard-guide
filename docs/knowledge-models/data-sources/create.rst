Create a data source
********************

Open :guilabel:`Knowledge Models` → :guilabel:`Data Sources` and click :guilabel:`Create`.
Enter a name, then save the source. Use a name that helps knowledge-model authors recognize its contents.

Continue in the source detail to define columns, import or enter values, and set the result display. See :doc:`detail`.
