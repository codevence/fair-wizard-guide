Documents
*********

Users with the :ref:`Edit ALL Projects<roles>` role permission can quickly browse documents across projects in their permitted scope by navigating to :guilabel:`Documents` from the projects menu. It is possible to search for a document by name or sort them using their name or creation timestamp.

Each document has a name, format, file size (once generation is complete), a link to the project it was generated from, and a template used for its creation. The document can be directly downloaded or deleted from the list.

If there is a document that was not generated due to an error, we can check the error message. If a document remains :guilabel:`Queued` or :guilabel:`In Progress`, contact the instance administrator or FAIR Wizard support with the project and document details.

    :figclass: guide-screenshot

With multiple workspaces, select the workspace whose project files or documents you want to browse. Organization-wide permissions may grant access to more than one workspace.
