.. _preview:

Preview
*******

We can quickly see how the resulting document would look like in the :guilabel:`Preview` tab.

.. figure:: /_static/earlier-interface/applications/data-management-planner/projects/list/detail/preview/preview-html.png
    :alt: Document preview in the project detail.

    **Outdated screenshot (4.x).** Document preview in the project detail.


Default Document Template Not Set
=================================

The preview uses the default document template. If there is no default document template set in the :ref:`project settings<default-document-template>`, we need to set it first.

.. figure:: /_static/earlier-interface/applications/data-management-planner/projects/list/detail/preview/document-template-not-set.png
    :alt: Preview only works when the default document template is set.

    **Outdated screenshot (4.x).** Preview only works when the default document template is set.


Download Preview
================

Not all formats can be displayed in the web browser, for example a MS Word document. In that case, we'll be able to download the document instead of previewing it.

.. figure:: /_static/earlier-interface/applications/data-management-planner/projects/list/detail/preview/download.png
    :alt: Some formats cannot be displayed in the web browser.

    **Outdated screenshot (4.x).** Some formats cannot be displayed in the web browser.
