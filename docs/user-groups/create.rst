Create a User Group
*******************

Open :guilabel:`User Groups` and choose :guilabel:`Create`. You need **Create User Groups**.
Enter a name and, optionally, a description. Choose whether the group is public or private, then save it.

Other users in the same workspace can see a public group. A private group is visible to its members and authorized administrators.

.. admonition:: Multiple workspaces

   Create the group in the workspace where it will be used. A group belongs to that workspace; its members must already be workspace members. Adding someone to a group does not grant workspace membership.

Continue with :doc:`detail` to add members and owners.
