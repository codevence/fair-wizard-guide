User Groups
***********

We can use user groups to share projects with several people at once, without adding each person separately.
A group has owners and members, and can be public or private. Project access depends on the group's project role and the user's other permissions.

Creating a group requires :guilabel:`Create User Groups`. :guilabel:`Manage User Groups` allows administrative management of groups; group owners can manage their own group through the supported actions.

.. admonition:: With multiple workspaces

   A user group belongs to one workspace and can contain only its members. Groups do not grant workspace membership by themselves. Removing a person from the workspace also removes their local group memberships.

See :doc:`/projects/detail/sharing` to grant a group access to a project.
