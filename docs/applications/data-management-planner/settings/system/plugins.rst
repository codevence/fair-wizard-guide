Plugins
*******

Plugins allows us to toggle and configure plugins. Available plugins are:

- **Replies Importer:** Importer for replies in JSON exported from Data Management Planner.
- **maDMP Importer:** Importer for maDMPs according to RDA DMP Common Standard.
- **Integration Hub:** Plugin for connecting Integration Hub to Data Management Planner.
