Support
*******

Here we can configure the support contact and help links shown to users. We need to keep these up to date so users know where to ask for help.

.. admonition:: With multiple workspaces

   A workspace can use its own support section where the organization allows an override. Otherwise it inherits the organization default.

Custom privacy-policy and terms destinations are configured for the hosted instance by the FAIR Wizard team, rather than edited through the former privacy settings. Contact the team if those destinations need changing.
