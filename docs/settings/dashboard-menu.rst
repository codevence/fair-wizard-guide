Dashboard & Menu
****************

Here we can configure dashboard content, announcements and custom menu links. For each link, we can set a title, URL and icon. The linked page should be accessible to the users who will use it.

.. admonition:: With multiple workspaces

   If the organization allows it, we can configure the dashboard and menu for a workspace. These settings replace the whole organization section. We can reset them to use the organization's settings again.

The login screen is configured separately in :doc:`/settings/login-screen`.
