Features
********

The Features settings control optional features offered by the instance, such as tours and the built-in AI Assistant where available.
Enabling a feature does not grant users all of its permissions; their roles and the required service configuration still apply.

The built-in AI Assistant provides help based on the guide. Connections that let an external AI client access instance data are managed separately in :doc:`/account/connected-ais`.
