Usage
*****

The Usage page shows how many projects, users, documents and files we have, along with reporting usage and plan limits.
Limits are applied to the organization as a whole.

.. admonition:: With multiple workspaces

   Plan limits are shared by all workspaces. Creating another workspace does not increase the available storage or number of projects.

Check usage before a large import or bulk document-generation task. If a limit is reached, review the affected resources or contact the FAIR Wizard team about the plan.
