.. _plugins:

Plugins
*******

Organization administrators enable available plugins and configure their default settings in :guilabel:`Settings` → :guilabel:`Plugins`.
The installed plugins and their configuration options depend on the instance.

.. admonition:: With multiple workspaces

   A workspace inherits the organization's available plugins and can disable one for its own area. When permitted by the organization, it can also replace a plugin's settings with local values or reset them to the default.
   Disallowing settings overrides clears local override values, but does not re-enable a plugin the workspace disabled.

Personal plugin settings belong to the user and remain the same when switching workspaces.
