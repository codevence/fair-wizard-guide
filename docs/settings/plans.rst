Plans
*****

The Plans page shows the current subscription and its applicable limits and features.
Professional uses a single workspace. Enterprise supports multiple workspaces, but can operate in single-workspace mode until that mode is enabled and the content is organized.

For current usage, see :doc:`/settings/usage`. For planning multiple workspaces, see :doc:`/administration/workspaces`.
