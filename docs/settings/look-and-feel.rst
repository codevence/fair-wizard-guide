Look & Feel
***********

Use the organization's :guilabel:`Look & Feel` settings to configure the application title, logo and primary color.
The application title is also used where earlier versions had a separate short title.

.. admonition:: With multiple workspaces

   Workspace names, descriptions and branding are managed through the organization's Workspaces area. A workspace can use its own logo and color, or use the organization's values.

Knowledge-model and document-template identifiers are managed on the content itself; there is no organization ID setting used to build three-part content identifiers in 5.0.
For navigation links and dashboard content, use :doc:`/settings/dashboard-menu`.
