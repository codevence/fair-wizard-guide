FAIR Wizard Registry
********************

The Registry distributes knowledge models, document templates and available translations. Use the import actions in FAIR Wizard to choose the required content and version.
Content identifiers and versions are separate in 5.0.

Registry accounts and keys
==========================

The 5.0 Registry uses individual accounts and API keys that we can name and revoke. A Registry key is different from a FAIR Wizard instance API key.
Ordinary Registry accounts can read and download content; publishing is restricted to Registry administrators.
We can revoke keys we no longer need in the Registry account settings.

If you maintain a Registry connection or use a self-hosted instance, coordinate the endpoint and credential change with the FAIR Wizard team or your deployment administrator. The 5.0 Registry API does not provide general compatibility with older clients.
For using imported content, see :doc:`/knowledge-models/library/import` and :doc:`/document-templates/library/import`.
