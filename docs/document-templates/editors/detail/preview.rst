Preview
*******

The :guilabel:`Preview` tab of :doc:`/document-templates/editors/detail/index` allows us to quickly check how our document template works and what the resulting document looks like for a selected project and document format.

We can select any **project** or **knowledge model editor** that we are allowed to view. Then, we select the desired **Format** (one of those specified on the :doc:`/document-templates/editors/detail/settings` tab of the editor).

After saving changes to the template's configuration or files, open the :guilabel:`Preview` tab again to regenerate the preview. The button beside the selected project or knowledge model editor opens it in a new browser tab.

.. figure:: /_static/screenshots/5.0/guide/dt-editor-preview.png
    :figclass: guide-screenshot
    :alt: Document Template Editor preview in FAIR Wizard 5.0
    :width: 800

    Document Template Editor preview.

.. note::

    Keep the preview open in a separate browser tab while editing files or settings. This makes it easier to compare changes with the generated output.
