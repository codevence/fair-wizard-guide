Create a document template editor
*********************************

We can create an editor by opening :guilabel:`Document Templates` → :guilabel:`Editors` and clicking :guilabel:`Create`. This requires :guilabel:`Use Document Template Editor`.
Start from an existing template where appropriate, or prepare a new template with its name, identifier, version and source language.

The identifier and version are separate values. There is no separate organization ID field that forms a three-part template identifier.
When choosing where to create the editor, we need to check whether it belongs to the organization or a workspace. The published template will be available in that library.

The editor contains files and metadata. See :doc:`detail/settings` for formats and compatibility, or use the :doc:`/development/document-templates/tdk` for local development.
