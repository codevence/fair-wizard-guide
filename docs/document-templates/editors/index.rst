Document Template Editors
*************************

Users with the :ref:`Use Document Template Editor<roles>` role permission can see and use document template editors in their permitted scope.

We can use the search field to search for a specific document template editor. The editors are sorted by when they were last updated but we can change that.

We can :doc:`/document-templates/editors/create` by clicking the :guilabel:`Create` button.

Open an item's three-dot menu to see the available actions:

- **Open Editor** - open the :doc:`/document-templates/editors/detail/index` (we can also click the name of the editor)
- **Delete** - to delete the document template editor (cannot be undone)
